# Google Business Profile Setup — Heart N Soul Catering

## Step 1: Claim or Create
1. Go to **google.com/business**
2. Sign in with **your Google account** (you manage it, not Tracy)
3. Search for "Heart N Soul Catering Del City"
4. If it exists → **Claim this business**
5. If not → **Add your business**
   - Business name: `Heart N Soul Catering`
   - Category: `Caterer`
   - Location: `Del City, OK 73115` (no street address visible if you're not storefront — select "I deliver/serve customers at their locations")
   - Service area: Del City, Oklahoma City, Midwest City, Edmond
   - Phone: `(405) 561-4437`
   - Website: `https://heartnsoulcateringok.com`

## Step 2: Verify
- Pick **phone verification** (fastest) or **email** (if available)
- If stuck with postcard, it takes 5-14 days

## Step 3: Fill Profile (do this while waiting for verification)

## Step 4: Get Google Reviews
Send Tracy this link (replace YOUR_PLACE_ID):
```
https://search.google.com/local/writereview?placeid=YOUR_PLACE_ID
```
She forwards it to past customers. **5-10 reviews = big SEO boost.**

## Step 5: Google Search Console
1. Go to **search.google.com/search-console**
2. Add property: `https://heartnsoulcateringok.com`
3. Verify ownership — since Cloudflare manages the domain, pick **DNS TXT record** method
4. Add the TXT record in Cloudflare DNS → verify
5. Submit sitemap: `https://heartnsoulcateringok.com/sitemap.xml`
